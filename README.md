# Double Wishbone Suspension System

## 📌 Project Overview

Designed and modeled a Double Wishbone Suspension System using SOLIDWORKS, focusing on suspension geometry, load distribution, structural performance, and material optimization.

<img src="images/complete-suspension.png" alt="Complete Suspension System" width="800"/>

---

## 🎯 Objectives

- Design and model a Double Wishbone Suspension System
- Analyze suspension geometry and load distribution
- Evaluate structural performance under applied loading
- Compare different materials for the control arms and spring
- Reduce weight while maintaining strength and stiffness
- Identify suitable materials for high-load conditions

---

- SOLIDWORKS

## 📐 Load Calculation

The suspension system was analyzed under calculated loading conditions.

- Car Weight = 1750 kg
- Passenger Load = 280 kg
- Total Mass = 2030 kg
- Total Load = 19,914 N
- Wheel Load = 4,978.5 N
- Dynamic Load = 7,170 N
- Spring Force = 3,435 N

### Control Arm Loads

- Lower Control Arm = 2,241 N
- Upper Control Arm = 1,494 N

---

## 🔬 FEA Analysis

The suspension assembly was imported into ANSYS for static structural analysis.

The analysis focused on:

- Total Deformation
- Equivalent Von Mises Stress
- Structural Behaviour under Static Loading
- Material Performance

<img src="images/fea-analysis.png" alt="FEA Analysis" width="800"/>

---

## 🧪 Material Selection

Different materials were analyzed for the control arms and spring.

### Control Arm Materials

- AA6061-T6 Aluminium Alloy
- AISI 4130 Chromoly Steel

### Spring Materials

- Chrome Silicon Steel
- 65Si7 Spring Steel

The material properties considered included:

- Young's Modulus
- Density
- Yield Strength
- Poisson's Ratio
- Ultimate Strength

---

## 📊 Control Arm Analysis

### Lower Control Arm

Applied Load: **2241 N**

- AA6061-T6 deformation = 0.43696 mm
- AISI 4130 deformation = 0.15017 mm

### Upper Control Arm

Applied Load: **1494 N**

- AA6061-T6 deformation = 0.30297 mm
- AISI 4130 deformation = 0.12202 mm

The analysis showed small deformation values under the applied loading conditions.

---

## 🌀 Spring Analysis

The spring was analyzed using different spring materials.

Applied Force: **3435 N**

- Chrome Silicon Steel
- 65Si7 Spring Steel

The remaining shock absorber components were kept as structural steel.

---

## 📈 Final Results

The complete suspension system was analyzed using the calculated forces:

- Lower Control Arm – 2241 N
- Upper Control Arm – 1494 N
- Shock Absorber – 3435 N

The final analysis was used to compare deformation and equivalent stress for different material combinations.

<img src="images/final-results.png" alt="Final Results" width="800"/>

### Material Comparison

| Component | Material | Key Characteristic |
|-----------|----------|--------------------|
| Control Arm | AISI 4130 | Higher strength and stiffness |
| Control Arm | AA6061-T6 | Lightweight and corrosion resistance |
| Spring | 65Si7 | Higher stiffness and fatigue strength |
| Spring | Chrome Silicon Steel | Shock absorption and durability |

---

## ⚙️ Selected Material Combination

### AISI 4130 + 65Si7

- **Control Arms:** AISI 4130
- **Spring:** 65Si7

The project analysis identified this combination as suitable for high-load conditions.
