# Double Wishbone Suspension System

## 📌 Project Overview

Designed and modeled a Double Wishbone Suspension System using CAD software, focusing on suspension geometry, load distribution, and structural performance.

## 🎯 Objectives

- Design and model a Double Wishbone Suspension System
- Analyze suspension geometry and load distribution
- Evaluate structural performance under applied loading
- Validate the design using simulation

## 🛠️ Tools & Technologies

- AutoCAD
- SolidWorks
- CAD Modeling
- Finite Element Analysis (FEA)

## 🔧 Project Work

- Created the suspension system design using CAD software
- Performed Finite Element Analysis (FEA)
- Evaluated stress and deformation
- Analyzed suspension geometry and load distribution
- Optimized and validated stress distribution and Factor of Safety (FOS)

## 📊 Analysis

The designed suspension system was analyzed through FEA to study:

- Stress distribution
- Deformation
- Load distribution
- Factor of Safety (FOS)

## 📈 Outcome

The simulation results were used to evaluate the structural performance of the suspension system and validate the design.
