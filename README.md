# Double Wishbone Suspension System

## 📌 Project Overview

Designed and modeled a Double Wishbone Suspension System using SOLIDWORKS, focusing on suspension geometry, load distribution, structural performance, and material optimization.

![Complete Suspension System](complete-suspension.png)

---

## 🎯 Objectives

- Design and model a Double Wishbone Suspension System
- Analyze suspension geometry and load distribution
- Evaluate structural performance under applied loading
- Compare different materials for the control arms and spring
- Reduce weight while maintaining strength and stiffness
- Identify suitable material combinations for high-load conditions

---

- SOLIDWORKS
- ANSYS

## 🔧 3D CAD Design

The complete double wishbone suspension system was designed and assembled using SOLIDWORKS.

The main components considered in the design include:

- Upper Control Arm
- Lower Control Arm
- Spring and Shock Absorber
- Steering Knuckle
- Wheel Hub
- Supporting Components

![CAD Design](cad-design.png)

---

## 📐 Load Calculation

The suspension system was analyzed under calculated loading conditions.

### Vehicle Loading

- Car Weight = 1750 kg
- Passenger Load = 280 kg
- Total Mass = 2030 kg
- Total Load = 19,914 N
- Wheel Load = 4,978.5 N
- Dynamic Load = 7,170 N
- Spring Force = 3,435 N

### Control Arm Loads

- Lower Control Arm = 2,241 N
- Upper Control Arm = 1,494 N

---

## 🔬 FEA Analysis

The completed suspension assembly was imported into ANSYS for static structural analysis.

The analysis was performed to evaluate:

- Total Deformation
- Equivalent (Von Mises) Stress
- Structural Behavior under Static Loading
- Material Performance

![FEA Analysis](fea-analysis.png)

---

## 🧪 Material Selection

Different materials were analyzed for the control arms and spring.

### Control Arm Materials

- AA6061-T6 Aluminium Alloy
- AISI 4130 Chromoly Steel

### Spring Materials

- Chrome Silicon Steel
- 65Si7 Spring Steel

The material properties considered included:

- Young's Modulus
- Density
- Yield Strength
- Poisson's Ratio
- Ultimate Strength

---

## 📊 Control Arm Analysis

Static structural analysis was performed on the control arms using ANSYS.

### Lower Control Arm

Applied Load: **2241 N**

- AA6061-T6 deformation = 0.43696 mm
- AISI 4130 deformation = 0.15017 mm

### Upper Control Arm

Applied Load: **1494 N**

- AA6061-T6 deformation = 0.30297 mm
- AISI 4130 deformation = 0.12202 mm

The analysis showed that both materials produced small deformation values under the applied loading conditions.

---

## 🌀 Spring Analysis

The spring inside the shock absorber was analyzed using different spring materials.

Applied Force: **3435 N**

Materials analyzed:

- Chrome Silicon Steel
- 65Si7 Spring Steel

The spring analysis was performed while keeping the remaining shock absorber components as structural steel.

---

## 📈 Final Results

The complete suspension system was analyzed by applying the calculated forces to:

- Lower Control Arm – 2241 N
- Upper Control Arm – 1494 N
- Shock Absorber – 3435 N

The final analysis was used to compare deformation and equivalent stress for different material combinations.

![Final Results](final-results.png)

### Material Comparison

| Component | Material | Key Characteristic |
|-----------|----------|--------------------|
| Control Arm | AISI 4130 | Higher strength and stiffness |
| Control Arm | AA6061-T6 | Lightweight and corrosion resistant |
| Spring | 65Si7 | Higher stiffness and fatigue strength |
| Spring | Chrome Silicon Steel | Good shock absorption and durability |

---

## ⚙️ Selected Material Combination

### AISI 4130 + 65Si7

The analyzed combination consists of:

- **AISI 4130** for Control Arms
- **65Si7** for Spring

This combination was identified in the project analysis as suitable for high-load conditions based on strength and stiffness.
